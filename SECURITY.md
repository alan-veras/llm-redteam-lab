# Security policy

This project is an intentionally vulnerable **lab**. The vulnerabilities in
`target/` are by design and are **not** security issues to report.

**Do report** (via GitHub issues, or privately to the address on the maintainer's
profile): a vulnerability in the *harness or tooling* itself — e.g. the attack
code can be made to reach outside the bundled target, the sandbox path
confinement can be escaped, or a dependency carries a real CVE.

Please do **not** use this project against any system you do not own or have
written authorization to test. See [DISCLAIMER.md](DISCLAIMER.md).
